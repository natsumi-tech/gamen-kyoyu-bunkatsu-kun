# 画面共有分割くん

Discord の画面共有（配信）を、配信者ごとに **好きな大きさの独立したウィンドウ** に切り出す Windows 用ツールです。

- 参加中の通話の配信を **自動で検出** して、配信者ごとにウィンドウを開きます
- ウィンドウは自由に移動・リサイズ・別モニターへ配置・最前面固定・全画面にできます
- Discord 本体は **「隠す」** ことができ、配信だけを見ることができます
- 隠している間は Discord を大きく描画させる **高画質モード** で、小窓でもくっきり

> Discord 非公式のツールです。Discord Inc. とは関係ありません。

## ダウンロード

[Releases](https://github.com/natsumi-tech/gamen-kyoyu-bunkatsu-kun/releases) から `画面共有分割くん.exe` をダウンロードして、ダブルクリックで起動します。インストールや Python は不要です。

動作環境: Windows 10 / 11（64bit）、Discord デスクトップアプリ（日本語版で確認済み）

初回起動時に「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください（署名のない exe のため）。

## 使い方

1. Discord でボイスチャンネルに参加し、通話画面を開く
2. 見たい配信をそれぞれ「配信を視聴」する（複数ならグリッド表示がおすすめ）
3. `画面共有分割くん.exe` を起動 → 配信ごとにウィンドウが自動で開きます

| 操作 | 内容 |
|---|---|
| 切り出しウィンドウを右クリック | 常に最前面 / 縦横比を保つ / 不透明度 / 範囲の選び直し / 名前変更 |
| 切り出しウィンドウをダブルクリック | 全画面の切り替え（Esc でも戻る） |
| 「Discord を隠す」スイッチ | 配信を映したまま Discord を画面から消す（最小化しても自動でこれに切り替わります） |
| 「隠している間の画質」 | そのまま / 自動 / 1440p / 4K |
| 「範囲を指定して追加」 | Discord 上の好きな範囲をドラッグで手動で切り出す |

詳しい使い方・注意点・困ったときの対処は [README.txt](README.txt) を見てください。

## 仕組みと安全性

- Discord が画面読み上げソフト向けに公開している「画面上の部品の名前と位置」（Windows UI Automation）を読み取って配信タイルを見つけ、その部分を Windows 標準の **DWM サムネイル** 機能で別ウィンドウに映しています
- Discord 本体の改造（クライアント MOD）・通信の傍受・自動操作は一切していません
- インターネット通信はしません。管理者権限も不要です
- 書き込むのは `%APPDATA%\画面共有分割くん\` の設定ファイルとエラーログだけです

### 制限

- Discord を本当に最小化すると Discord が描画を止めるため映りません（「隠す」を使ってください）
- 映せるのは Discord の画面に表示されている配信だけです。画質の上限は元の配信の解像度です
- 配信タイル上の名前や「ライブ」表示もそのまま映ります
- 英語版 Discord での自動検出は未確認です（手動での切り出しは使えます）

## ソースからビルド

Python 3.12（64bit）が必要です。

```bat
build.bat
```

`dist\画面共有分割くん.exe` ができ、最後に SHA256 ハッシュ値が表示されます。

| ファイル | 内容 |
|---|---|
| `stream_splitter.py` | 本体（画面・切り出しウィンドウ・DWM サムネイル） |
| `discord_detect.py` | 配信タイルの自動検出（UI Automation） |
| `hider.py` | Discord を「描画を止めずに」隠す処理 |
| `ui_widgets.py` | ダークテーマと自作ウィジェット |
| `build.py` / `build.bat` | exe のビルド |
