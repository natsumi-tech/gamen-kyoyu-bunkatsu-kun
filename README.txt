画面共有分割くん - Discord の配信を、好きな大きさの別ウィンドウに切り出すツール
=====================================================================

■ 使い方（自動モード）
1. Discord でボイスチャンネルに参加し、通話画面を開く
2. 見たい配信をそれぞれ「配信を視聴」する（複数ならグリッド表示がおすすめ）
3. 画面共有分割くん.exe をダブルクリック
   → 画面に出ている配信を自動で見つけて、配信者ごとに独立ウィンドウが開きます
4. ウィンドウは自由に移動・サイズ変更・別モニターへ移動OK
   位置や大きさは配信者ごとに記憶され、次にその人が配信したときも同じ場所に出ます

- 配信が終わる／Discord で別の画面を開くと、ウィンドウは「表示されていません」と出て待機します
- 不要なウィンドウは閉じればOK（その配信が終わるまで再表示されません）
- 「通話内で配信中の人」の数が表示中の数より多いときは、Discord 側でまだ視聴していない配信があります

■ 手動モード
「＋ 範囲を指定して追加」で、Discord 上の好きな範囲をドラッグで切り出せます。

■ 切り出しウィンドウの操作
- 右クリック : 常に最前面 / 縦横比を保つ / 不透明度 / 範囲の選び直し / 名前変更
- ダブルクリック : 全画面の切り替え（Esc でも戻る）

■ Discord を隠す
- 「Discord を隠す」スイッチをオンにすると、配信を映したまま Discord が画面から見えなくなります
  （一番右のモニターの右端に 2px だけ残して最背面に移動しています）
- Discord を最小化しても、自動で「隠す」に切り替わります（詳細設定でオフにできます）
- 戻すとき: タスクバーの Discord をクリック / スイッチをオフ / 画面共有分割くん を終了

■ 隠している間の画質（高画質モード）
- 隠している Discord は画面外にあるので、モニターより大きく描画させて配信タイルを高解像度にします
  そのまま : 隠す前の大きさ
  自動     : 配信 1 件 → 2560×1440 / 4 件まで → 3840×2160 / それ以上 → 5120×2880（おすすめ）
  1440p / 4K : 固定
- 元の配信の解像度（720p / 1080p など）より上はきれいになりません
- Discord の描画が大きくなる分、GPU の負荷が少し増えます
- 手動で範囲指定した切り出しは、Discord の大きさが変わると範囲がずれます（自動モードは追従します）

■ 大事な注意
- 本当に最小化された状態では Discord が描画を止めるので映りません（上の「隠す」を使ってください）
- 画質は Discord 上での表示サイズが上限。Discord を大きめに開いておくときれい
  （小さいタイルのまま切り出すと、拡大してもぼやけます）
- 配信タイル上の名前や「ライブ」表示もそのまま映ります

■ 配置の保存
- 終了時に自動保存されます（保存場所: %APPDATA%\画面共有分割くん\layout.json）

■ 困ったとき
- Discord が画面から消えたまま戻らない
  → 画面共有分割くん を起動すると自動で元に戻ります
  → それでもダメなら: タスクバーの Discord をクリックしてから「Windows キー + ↑」で最大化
- 動きがおかしいとき: %APPDATA%\画面共有分割くん\error.log を送ってください
  （中身はエラーの内容だけです。送る前に開いて確認できます）
- 英語版の Discord では自動検出できない可能性があります（日本語版で確認済み）。
  そのときは「範囲を指定して追加」で手動で切り出してください

■ 仕組みと安全性
- Discord が画面読み上げソフト向けに公開している「画面上の部品の名前と位置」を読み取って
  配信タイルを見つけ、その部分を Windows 標準の DWM サムネイル機能で映しています
- Discord 本体の改造・通信の傍受・自動操作は一切していません
- インターネット通信は一切しません。管理者権限も不要です
- 書き込むのは %APPDATA%\画面共有分割くん\ の設定ファイル（layout.json）とエラーログ（error.log）だけです
  layout.json には、ウィンドウ位置を覚えるために配信者のユーザー名が保存されます（PC の外には出ません）
- 初回起動時に Windows SmartScreen の警告が出たら「詳細情報」→「実行」で起動できます
